Understanding Text Hierarchy

Headings are crucial for structuring your content. We just used an h1 and an h2. As we go deeper into topics, the headings get smaller, but they remain structurally important.

Inline Formatting: The Basics

Sometimes you need to emphasize a word. You can use the italic tag for visual style, or the em tag for actual structural emphasis. Similarly, you can use the bold tag, but the strong tag is preferred for conveying importance.

Editing and Modifying Text

During the drafting process, you might need to show changes. For example, the old syntax is deprecated and broken, while the new syntax is clean and modern. Using these tags shows exactly what was removed and what was added.

Scientific and Mathematical Data

As a developer, you will build tools for various industries. If you are building an app for chemists, you must know how to write H2O and CO2 correctly. If you are building a calculator, writing equations like a2 + b2 = c2 requires precision.
