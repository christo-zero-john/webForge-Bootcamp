### Task 1: Basic Structure & Simple Formatting

This group covers the mandatory boilerplate and the basic text elements needed to get a simple page off the ground.

- `<!DOCTYPE html>`: Declares that the document is modern HTML5 - _(Invisible)_

- `<html>`: The root element that wraps everything else on the page - _(Invisible)_

- `<head>`: Contains the metadata and the title of the document - _(Invisible)_

- `<title>`: Sets the name that appears in the browser tab - _(Invisible)_
- `<body>`: The container that holds all the visible content you actually see on the screen - _(Invisible)_

- `<h1>` - `<h4>`: Defines headings for structuring the main content hierarchy - **Heading 1**

- `<p>`: Defines a standard block of text or paragraph - This is a normal sentence.

- `<b>`: Makes text visually bold without adding semantic weight - **bold text**
- `<i>`: Italicizes text purely for visual styling - _italic text_
- `<u>`: Draws a solid line under the text - <u>underlined text</u>
- `<mark>`: Highlights the text, typically with a yellow background - <mark>highlighted text</mark>
- `<sup>`: Renders the text as a superscript (raised higher) - x<sup>2</sup>
- `<sub>`: Renders the text as a subscript (dropped lower) - H<sub>2</sub>O

### Task 2: Advanced Hierarchy, Semantic Styling & Containers

This group covers the tags introduced in the expanded, more realistic document, including the deeper heading levels, semantic formatting, and structural containers.

- `<h5>` - `<h6>`: Defines the lowest levels of headings for fine-grained structure - **Heading 6**

- `<div>`: A generic, block-level container used to group elements together - _(Invisible without CSS)_

- `<span>`: A generic, inline container used to target a specific piece of text - _(Invisible without CSS)_

- `<strong>`: Makes text bold and tells the browser the text is highly important - **strong text**
- `<em>`: Italicizes text to give it structural emphasis or a change in voice - _emphasized text_
- `<del>`: Strikes a line straight through text to show it was removed - ~~deleted text~~
- `<ins>`: Underlines text to indicate it was newly inserted - <u>inserted text</u>
- `<small>`: Shrinks the text size, perfect for copyrights or fine print - <small>small disclaimer text</small>
